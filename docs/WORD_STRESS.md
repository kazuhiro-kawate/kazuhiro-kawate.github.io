# 最新の定義と初期生成

現在は3本でσ₃=(3 1)を扱い、外側2本を直接交差させ、中央線を水平に描く。斜めの中央は直線、出入りの角だけを滑らかに丸める。上限64は入力の項数。初期表示だけは毎回1〜6項を生成する。500回の生成と乱数の端点で上限・合法性・箱の不変性を検証済み。

以下は4本版の時点の測定記録であり、現在のσ₃の定義とは区別する。

# 交差列の長さと仕様

2026-11-11の検証。3本ではσ₃が定義できないため4本へ拡張。実行順は左から右。対称モノイダル圏の対称性を扱い、σᵢ²は表示上そのまま残す。任意編集と等式による変形は区別する。

## モデルの測定

上限を外したテスト用のモデルで、レイアウト生成を20回ずつ実行した中央値。Node実行環境の計算時間であり、描画や実機のフレームレートの測定ではない。

| 交差数 | 図式幅（px） | 線の制御点数（4本合計） | レイアウト中央値（ms） |
| --- | ---: | ---: | ---: |
| 32 | 12,900 | 282 | 0.034 |
| 64 | 24,420 | 538 | 0.052 |
| 128 | 47,460 | 1,050 | 0.102 |
| 256 | 93,540 | 2,074 | 0.196 |

計算だけは短時間でも、128〜256では横移動と列の把握に必要な範囲が非常に長くなる。操作性を優先し、公開する操作は64までとした。128/256を実UIで操作したという意味ではなく、モデル用のストレス試験である。

## 採用仕様

- 32以上：案内を表示。入力欄は高さを制限してスクロール可能。
- 64：追加ボタンを無効化。選択した既存項の置換、削除、空にする操作は可能。65以上のモデル入力は変更を加えず拒否する。
- σ²の図式上の配置も同じ上限に数える。2枠必要なため、63/64では配置を無効化する。入力と図式で別々の上限は設けない。
- 勝手な切り詰めやσ²の簡約をしない。空の交差列では対称性の部分だけが恒等射になり、箱の射は残る。
- 入力実行、σ²配置・除去、Undo/Redoは同じモデルに同期する。入力欄から配置を始めた場合は更新後の入力欄へ戻る。
- 描画は表示幅に左右440pxの余白を加えたSVGへ限定。長いキャンバス全幅のフィルター画像を作らない。
- 図式を縮めてもカメラ位置の急変を避けるため幅は保持し、Resetで初期の列・箱・幅へ戻す。

## 実ブラウザー

64個のσ₃を入力・実行して64項が残ること、追加とσ²配置が無効になること、既存項を選べば置き換えられることを確認。24,420pxのキャンバスに対し、SVGは表示幅に応じて1,985〜2,145px。64個のハンドルで有限補間が終了し、終了時のanimating=falseと64フレームの更新を観測した。これは固定の所要時間やフレームレートの保証ではない。右端への移動後も4本のパスと正しい境界ラベルを表示し、縦位置は0だった。

σ²を含む列の実行、図式へ配置した際の2項の追加、除去とUndo、64から空の列への実行とUndoによる復元を確認。320×568でも4ボタンでσ₃²を追加・実行でき、横のはみ出しと文書の縦スクロールはなかった。動きを抑える設定では実行直後にanimating=false。

モデル・補間・合成・任意列の計79,682検査と静的11テストが通過。任意列の試験には350回の再現可能な混合操作、0/64/65/256項、σ₃、σ²、境界置換、入力拒否時の原子性、履歴、各補間フレームの接続を含む。最終ロードの検証タブでは警告・エラー0件。
