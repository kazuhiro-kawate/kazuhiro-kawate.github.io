公開先：https://limxiao.github.io/（GitHubユーザー名：limxiao、表示名：Kazuhiro Kawate）。サイト内の氏名表記は従来どおり。以下の未公開・旧URLの記載は制作時点の記録です。

図式の中だけで探索・閲覧する個人研究サイト。縦ホイールは横スクロールに変換し、詳細は箱から開くパネルで読む。HTML / CSS / SVG / JavaScript の静的サイトで、外部ライブラリ・CDN・WebGL は使用しない。

## ローカルで見る

このディレクトリで実行し、`http://127.0.0.1:4173/` を開く。

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

Ctrl+Cで終了する。配信済みHTMLを同梱しているため、閲覧前のビルドは不要。Python 3.9以降で生成できる（検証環境は3.12）。

## 操作

- 縦ホイール：左右へ探索。横方向のトラックパッド、タッチのスワイプにも対応。
- 箱をドラッグ：接続を維持しながら変形。5px以上の移動をドラッグとして扱い、クリックと区別。
- 箱をクリック：詳細パネル。パネル内のホイールは通常の縦スクロール。
- 箱下のハンドル：Tabでフォーカスし、左右キーで移動。Shiftで大きく移動。Enterで確定、Escapeで取り消し。
- 操作領域にフォーカス：左右キー・Home・Endで探索。下の番号ボタンでも移動可能。
- 合成：箱の＋で選び、直列 ∘ / 並列 ⊗ でまとめる。並列では「恒等射を含める」をオン・オフできる。合成箱を選び「展開」で元へ戻す。
- σ²を置く：図式内の好きな位置をクリック。高さで隣接する2本を選ぶ。キーボードでは左右で位置、上下で2本、Enterで配置。各σ²の×でその組を除去。
- Reset：箱を初期位置へ。Guide：説明と動きの削減設定。
- 詳細パネル：EscapeまたはCloseで閉じる。通常ページへのリンクも用意。

OSの `prefers-reduced-motion` ではパララックス、線のカーソル反応、スナップの補間を無効化。横スクロール・コンテンツ閲覧はそのまま利用できる。

## 交差を越える操作への更新

箱は対象A/B/Cに属するデータとして管理する。位置を固定範囲へ制限する初版の実装を置き換え、ワイヤーに沿って交差を越えられるようにした。必要に応じて同じ線の後続の箱も移動し、同じ対象に割り当てられた箱の初期順序を守る。

- 箱・σを左右へドラッグ。上・下キーによる自由な縦移動は廃止し、左右キーでワイヤーをたどる。
- 交差列：σ₁・σ₂・σ₃・削除のボタンで列を作り、実行する。列の中の交差を選ぶと置換・削除でき、末尾へで追加に戻る。
- 交差列内の編み替え：適用できるσᵢσᵢ₊₁σᵢとσᵢ₊₁σᵢσᵢ₊₁を切り替える。途中の箱は自然性で運ぶ。
- σ²：隣接する対称性の往復を挿入・除去。
- Undo / Redo：変形の履歴。Cmd/Ctrl+Z、Shift+Cmd/Ctrl+Zにも対応。
- 通常のドラッグではカメラを固定。箱を持ったままホイールで探索できる。Shiftを押しながら画面端へ持つと横に探索する。
- 箱とワイヤーの端点は同じ有限アニメーションで補間し、動きの削減設定では補間しない。補間中の絵は公理による変形の視覚表現。

型付きモデルは `assets/diagram-model.js`、補間は `assets/diagram-motion.js`、入力と画面表示は `assets/site.js`。現在は3本の対象と5つの単項射からなる範囲を扱い、任意の多入力・多出力の射を追加する汎用エディタは未実装。

追加検証はローカルサーバーの `/tests/model.html` を開く。Nodeがある環境では次でも実行可能（実行時の配信にはNodeは不要）。

```sh
node tests/model.test.mjs
node tests/motion.test.mjs
node tests/composition.test.mjs
node tests/word.test.mjs
```

## 合成箱と恒等射

既存の生成射をまとめ、直列はg∘f、並列は異なる対象の因子のテンソル積を表示する。合成箱から元の研究セクションを開ける。並列で恒等射を含めると全3本がポートになり、含めなければ選択した因子の対象だけがポートになる。選択は各合成箱に保存され、Undo / Redoでも復元する。

対象が隣接しない場合、箱の囲みに通路を残して対象外のワイヤーを通す。これは既知の因子をまとめる表示であり、対象外の線を箱の型に加えない。入れ子の並列合成では既知の因子を取り出して再度まとめる。任意の未知の多入力・多出力射に対する汎用合成器ではない。詳しい意味はGuideに記載。

## 解説と研究ノートの分離

Guide（f:A→A）はサイトの操作とストリング図式の解説、Notes（j:C→C）は従来の研究ノートの入口。別々の箱・Markdown・パネル・通常ページを持つ。対称性の表示実験と動きの削減設定はGuideへ移した。README.htmlは研究ノートの入口として維持する。現在は対象ごとの初期順序を保ち、合成箱が別の線の箱を押す場合も順序制約を伝播する。

左端の線は右端と同様に水平。左右の外端ではカーソルによるたわみを付けない。氏名を上へ動かし、その下にはPERSONAL WEBSITEだけを置く。合成オプションは右上の合成ボタンの下に右揃えする。

## 任意の交差列

初期配置は左からGuide=f、About=g、Research=h、Projects=i、Notes=j。このサイトでは3本のワイヤーでσ₁=(1 2)、σ₂=(2 3)、σ₃=(3 1)と定義する。σ₃は通常の隣接交換の添字とは区別し、外側2本を直接交差させ、斜めの中央部分は直線、水平線との接続だけを滑らかに丸める。中央の線は水平に描画する。列の編集は射や境界の置換を変える場合があるため、同じ射を保つ変形とは区別する。

右上の交差列、または図式内のσ列を押すと入力欄を開く。σ₁・σ₂・σ₃・削除の4ボタンで編集。交差を選ぶとその位置を置換・削除でき、末尾へで追加に戻る。1/2/3とBackspace/Deleteにも対応。実行時に有限補間し、動きを抑える設定では直ちに反映する。σ²を自動で消さない。図式側の挿入・除去・Undo/Redoは入力欄にも反映する。

上限はσ²の配置分を含め64交差。32から案内を出し、64で追加を無効にする。既存項の置換・削除は可能。残り1枠以下ではσ²配置を無効にする。空の列も許し、入力を切り詰めない。列を縮めた後もカメラを固定するため既存の幅は保持し、Resetで初期化する。

長い列でもSVGの幅は表示幅+880px程度に保ち、表示周辺のパスだけを描画する。HTMLのキャンバスが伸びても、光沢フィルターの画像をキャンバス全幅に広げない。CSS/JSのURLは内容のハッシュ付きで生成し、更新時の古いアセットの混在を防ぐ。

長い列の測定と採用仕様はdocs/WORD_STRESS.mdを参照。

## 初期列のランダム化

ページを開くたび1〜6項を生成する。各項はσ₁・σ₂・σ₃から選び、セッション保存を利用できるときは直前と同じ列を避ける。初期生成の6項制限と手動編集の64項制限は別。Resetはそのページを開いたときの列・箱へ戻す。

## 箱の接続先と交差列の順序

各箱の対象A/B/Cもページ更新時にランダムに割り当てる。Guide→About→Research→Projects→Notesの初期の横方向の順序を保持し、型・色・ポートは接続先に合わせる。Resetは今回の初期配置を復元する。同じ対象の箱を運ぶときの順序制約も、この割り当てに従う。

交差列はドラッグで並べ替えられる。6pxの移動でドラッグを開始し、移動先を強調表示する。行をまたぐ操作、端での自動スクロール、領域外へのドロップによる取り消しに対応。選択後の左右ボタン、Shift+左右キーでも移動できる。変更は実行で図式に適用する。
